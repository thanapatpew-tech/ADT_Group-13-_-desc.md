# KAITO DORMITORY - ระบบค้นหาหอพัก

โปรเจกต์นี้คือเว็บแอปพลิเคชันที่เขียนด้วยภาษา C ทำงานแบบ CGI (Common Gateway Interface) เพื่อคำนวณและจัดอันดับหอพักตามค่าน้ำหนัก (ราคา, ระยะทาง, สิ่งอำนวยความสะดวก) โดยใช้โครงสร้างข้อมูลแบบ Max-Heap ในการประมวลผลผลลัพธ์ที่ดีที่สุด

## 🛠 เครื่องมือ ภาษา และ Library ที่ต้องใช้
- **ภาษา:** C
- **Compiler:** GCC (MinGW-w64 สำหรับ Windows หรือ Clang สำหรับ Mac/Linux)
- **Library มาตรฐานที่ใช้:** `<stdio.h>`, `<stdlib.h>`, `<string.h>`, `<float.h>`, `<limits.h>`

## ⚙️ ขั้นตอนการติดตั้งและวิธีการเปิดใช้งานโปรแกรม

โปรแกรมนี้ออกแบบมาให้ทำงานเป็น CGI Script ซึ่งแสดงผลลัพธ์เป็นโค้ด HTML สามารถเลือกทดสอบการทำงานได้ 2 วิธี ดังนี้:

### วิธีที่ 1: รันผ่าน Terminal / Command Prompt (เพื่อตรวจสอบ Output พื้นฐาน)

2. พิมพ์คำสั่งเพื่อ Compile โค้ดให้เป็นไฟล์ Executable:
